### Preprocessing notebook structure (derived from EDA)

The action items above translate directly to a preprocessing pipeline with these stages. We'll build the notebook in this order:

1. **Load & normalise** — Unicode NFKC on all text, repair smart-punct, fix Excel-date CAS strings.
2. **Recompute derived columns** — `age_bucket` from `age`; canonical descriptor list from text via synonym lookup; deduped recipe variants.
3. **Build canonical bridge tables** — note bridge (50/221/396/216), accord bridge (32/203/64/16), recipe-defaults bridge.
4. **Resolve aliases** — 251 shared-CAS notes consolidated; 23 malformed-CAS rows fixed.
5. **Filter & flag** — drop dormant accords if shrinking output space, flag the 527 descriptor-avoid contradictions.
6. **Feature engineering for notes** — categorical embeddings (chemical_family, odor_family, volatility_class), numeric with imputation indicators, optional CAS→SMILES→embedding for the 437 with chemistry.
7. **Feature engineering for examples** — multi-hot descriptors (with synonym recovery), multi-hot avoids, categorical demographics, tokenised user_text.
8. **Stratified splits** — 80/10/10 stratified on primary accord; rare-class pooling for the 5 accords with <10 examples.
9. **Persist** — clean parquet/pickle files for the modeling notebook.
